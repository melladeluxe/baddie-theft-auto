# Baddie Theft Auto: Glam City

Responsive browser driving game — "Baddie Theft Auto" — a playful, neon-styled mini-game where you collect Clout and Cash while avoiding the Vibe Police.

Features included in this repo:

- Responsive, hi-DPI canvas scaling (works on mobile and desktop)
- Delta-time based movement for consistent gameplay across frame rates
- Normalized keyboard input, on-screen touch controls, optional tilt steering
- Safe collectible removal (iterates backwards when splicing)
- Heat escalation and dynamic police spawning
- High score persistence via localStorage
- Small WebAudio SFX (no external assets required)

Play: https://melladeluxe.github.io/baddie-theft-auto
